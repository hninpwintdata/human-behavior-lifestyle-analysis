\# Human Behavior \& Lifestyle Analysis



\## Project Overview

This project explores human behavior and lifestyle patterns using a dataset of 1,000 participants. It examines relationships between sleep, screen time, exercise, stress, satisfaction, social media use, and other lifestyle factors.



The goal is to practice data analysis and transform raw data into meaningful insights using Python, SQL, Excel, and Power BI.



\## Tools \& Technologies

\- \*\*Python:\*\* Data cleaning, exploratory data analysis (EDA), and visualization

\- \*\*SQL (MySQL):\*\* Data querying and analysis

\- \*\*Microsoft Excel:\*\* Data analysis, charts, and dashboard

\- \*\*Power BI:\*\* Interactive dashboard and visual reporting



\## Dataset

\- \*\*Rows:\*\* 1,000 participants

\- \*\*Columns:\*\* 12

\- \*\*Topics:\*\* Demographics, sleep, screen time, exercise frequency, social media use, stress, monthly spending, satisfaction, and motivation



\## Key Findings

\- More frequent exercise was associated with lower average stress levels and higher average satisfaction levels.

\- Screen time and sleep duration showed a negative correlation.

\- Stress and satisfaction levels showed a negative correlation.

\- Social media usage showed a positive correlation with stress levels.



\*These findings describe associations in this dataset and do not establish causation.\*
